Cài đặt

Chọn hệ điều hành. Cài trong vài phút, không cần tài khoản.

Windows 10/11 (64-bit)

Cài cho riêng bạn, không cần quyền quản trị.

Tải Sheetstamp-Setup-x64.exe
  1. Tải Sheetstamp-Setup-x64.exe bằng nút ở trên.
  2. Bấm đúp vào file. Không cần quyền quản trị.
  3. Nếu Windows hiện “Windows đã bảo vệ PC của bạn”: bấm Thông tin thêm, rồi Vẫn chạy.
Kiểm tra file đã tải

Mở PowerShell tại thư mục tải về và chạy lệnh dưới, rồi so với dòng tương ứng trong SHA256SUMS.txt. 

Get-FileHash .\Sheetstamp-Setup-x64.exe -Algorithm SHA256

Ubuntu 22.04 / 24.04 (64-bit)

Gói .deb là cách cài chính.

Tải Sheetstamp-x64.deb AppImage
  1. Mở terminal trong thư mục tải về và chạy: 
    sudo apt install ./Sheetstamp-x64.deb
  2. Mở Sheetstamp từ menu ứng dụng.
  3. Dùng bản AppImage trên Ubuntu 24.04 thì cần cài thêm libfuse2t64 (sudo apt install libfuse2t64). Bản .deb không gặp vấn đề này.
Kiểm tra file đã tải

Chạy lệnh dưới trong thư mục tải về, rồi so với dòng tương ứng trong SHA256SUMS.txt. 

sha256sum Sheetstamp-x64.deb

macOS: sắp có

Chưa có bản công khai. Bản macOS sẽ được phát hành khi có thể ký và công chứng với Apple.

Phiên bản Electron đi kèm được hỗ trợ bảo mật đến 27/04/2027; hãy cập nhật Sheetstamp trước thời điểm đó.
