Four steps, one thing at a time

Install

Pick your system. A few minutes, no account.

Windows 10/11 (64-bit)

Per-user install, no administrator rights.

Download Sheetstamp-Setup-x64.exe
  1. Download Sheetstamp-Setup-x64.exe with the button above.
  2. Double-click the file. No administrator rights needed.
  3. If Windows shows “Windows protected your PC”: click More info, then Run anyway.
Verify the download

Open PowerShell in the download folder, run the command, and compare it with the matching line in SHA256SUMS.txt.

Get-FileHash .\Sheetstamp-Setup-x64.exe -Algorithm SHA256

Ubuntu 22.04 / 24.04 (64-bit)

The .deb package is the main way to install.

Download Sheetstamp-x64.deb AppImage
  1. Open a terminal in the download folder and run: 
    sudo apt install ./Sheetstamp-x64.deb
  2. Open Sheetstamp from the application menu.
  3. The AppImage on Ubuntu 24.04 also needs libfuse2t64 (sudo apt install libfuse2t64). The .deb does not.
Verify the download

Run the command in the download folder and compare it with the matching line in SHA256SUMS.txt.

sha256sum Sheetstamp-x64.deb
